Read me first

Built to work offline: the site code, lyric editor, local audio analysis, chords, diagrams, metronome, library, backups, and fretboard have no subscription or server dependency. YouTube video embedding requires an internet connection.

Chord detection: Uses local short-time FFT and chroma/template scoring of 24 major/minor triads. It estimates harmonic changes but cannot guarantee original recording chords, detailed inversions, slash chords, or extensions. Aligning chords and lyrics still benefits from manual editing.

YouTube: The official embedded player can display supported videos and report playback time. It does not expose media audio to standalone websites. No YouTube audio downloads or automatic extraction are provided.

Microphone: Optional Web Audio pitch estimate for a single guitar string; browsers usually require localhost/HTTPS for microphone permission. It is not a machine-learning chord feedback system.

Audio separation: No true vocal/instrument stem separation is included: robust separation generally needs heavy local ML models and a dedicated install. A basic EQ is available for local audio.

Lyric timing: Assisted manual timing works through line selection and the local audio or embedded video's current time. Fully automatic vocal-to-text alignment/transcription is not included, as it would require speech-recognition models.

Capo chords: Capo shapes are calculated from the sounding chords and chosen capo fret. Chord diagrams cover common major/minor shapes; some complex chords and slash chords show a text label without a diagram. The recommended capo uses a simple shape-comfort heuristic, not a guarantee of easiest fingering for every guitarist.

Storage and privacy: Songs are stored locally in your browser. Audio files stay on your computer; this website does not upload them. Data may be cleared if you clear site data or use private browsing. Export backups regularly.

To run reliably on Windows: Open index.html in Chrome or Edge. If you want microphone access, run a local server from this directory using py -m http.server 8000, then open http://localhost:8000. This requires Python installed; a Windows launcher and instructions are included in the ZIP.
