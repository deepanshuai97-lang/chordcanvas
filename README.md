# ChordCanvas

Free, local-first guitar studio: lyric chord suggestions, MP3/WAV chord estimates, capo adjustment and chord diagrams, metronome, local songbook, and YouTube embed.

## Samsung

Visit https://deepanshuai97-lang.github.io/chordcanvas/ in Chrome, then choose **Add to Home screen** > **Install** when offered.

## Publish

In GitHub **Settings > Pages**, choose **Deploy from a branch**, **main**, **/(root)** and Save.

## Limits

MP3 chord detection is approximate and is not supported directly from YouTube links. Local songs are saved in browser storage, not on GitHub. Export backups regularly. Microphone tools require browser permission and may have limited support on Android.
